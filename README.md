# Hotel Pet

Projeto desenvolvido para a disciplina de Programação Web II, do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

O Hotel Pet é um sistema de gerenciamento de estadia de animais de estimação em períodos específicos.

O projeto tem como referência o protótipo disponibilizado pela professora no Figma. Nesta disciplina, o objetivo é desenvolver as interações e a parte dinâmica do site utilizando JavaScript, dando continuidade à estrutura criada na disciplina de Programação Web I.

A versão desenvolvida corresponde à **visão do Gerente**, que inclui as funcionalidades previstas para clientes e funcionários, além das funções específicas de gerenciamento.

## Funcionalidades representadas

- Login e cadastro de usuário;
- Listagem e pesquisa de reservas;
- Cadastro de novas reservas;
- Visualização e edição de reservas;
- Acompanhamento da estadia do pet;
- Cadastro, pesquisa e edição de pets;
- Gerenciamento de usuários e alteração de suas funções;
- Configurações do sistema;
- Alteração das informações do perfil do gerente.

## Etapas do projeto

- **Semana 1 — Navegação:** implementação da navegação entre as telas utilizando JavaScript.
- **Semana 2 — Buscas:** implementação das funcionalidades de busca.
- **Semana 3 — Tabelas:** implementação das funcionalidades de edição das tabelas.

## Tecnologias utilizadas

- HTML5
- CSS
- JavaScript

## Observações

O projeto não possui backend ou banco de dados. Os elementos e dados são estáticos, conforme as orientações da atividade.

As funcionalidades serão desenvolvidas gradualmente, de acordo com as etapas propostas na disciplina.
