# Hotel Pet

Projeto desenvolvido para a disciplina de Programação Web I do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

O Hotel Pet é um sistema de gerenciamento de estadia de animais de estimação em períodos específicos.

Nesta primeira etapa do projeto foi desenvolvida a estrutura das páginas utilizando HTML, tendo como referência o protótipo disponibilizado pela professora no Figma.

A versão desenvolvida corresponde à **visão do Gerente**, que possui as funcionalidades previstas para clientes e funcionários, além das funções específicas de gerenciamento.

## Funcionalidades representadas

- Login e cadastro de usuário;
- Listagem e pesquisa de reservas;
- Cadastro de novas reservas;
- Visualização e edição de reservas;
- Acompanhamento da estadia do pet;
- Cadastro, pesquisa e edição de pets;
- Gerenciamento de usuários;
- Alteração da função dos usuários;
- Configurações do sistema;
- Alteração das informações do perfil do gerente.

## Tecnologias utilizadas

- HTML5
- CSS3

> Nesta etapa do projeto, foram desenvolvidas a estrutura das páginas em HTML5 e a estilização da interface utilizando CSS3.

## Observações

O projeto é estático nesta etapa e não possui backend ou banco de dados.

Os elementos apresentados representam as telas e funcionalidades previstas para o sistema.
