# Testes - Hotel Pet

## Semana 1 - Navegação

### Objetivo

Verificar o funcionamento da navegação entre as telas do sistema Hotel Pet, utilizando JavaScript.

### Testes

- [ ] Verificar se a página inicial é exibida corretamente.
- [ ] Verificar se os botões de navegação funcionam.
- [ ] Verificar se é possível navegar entre as telas do sistema.
- [ ] Verificar se as telas são exibidas corretamente durante a navegação.
- [ ] Verificar se não ocorrem erros no console do navegador durante a navegação.

### Resultado dos testes

Os itens devem ser marcados após a realização de cada teste no navegador.

### Observações

Esta etapa contempla a navegação entre as telas do sistema. As funcionalidades de busca e edição das tabelas serão desenvolvidas nas próximas etapas da atividade.
